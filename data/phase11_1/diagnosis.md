## Routing failures (E06, E08, E09, E14): classification only
All four are router-level and are **not fixed** in this phase (instruction: classify first; no router change without a fresh-set evaluation, and none was proposed). None of them fabricated an answer: E06/E08 returned "documentation unavailable", E09 "unable to verify", E14 "out of scope" - each is a wrong-but-honest abstention, so the cost is a missed answer, not a false one.
